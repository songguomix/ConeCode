# ConeCode 2.4.15

- macOS Computer Use 可以直接选择并截图后台窗口。输入前会确认目标窗口，浮动面板不再被当成文档的键盘焦点。
- 记忆提取请求将已有记忆按固定顺序放在动态任务信息之前，提高缓存前缀的可复用性。排队消息和编辑后重发会按当前任务重新检索记忆。
