**强烈建议更新。** 本版优化了长会话和连续工具调用的提示词缓存，并修复了 GitHub Release 上传续传与 RSI 验证中的问题。

## 更新内容

- **提高提示词缓存命中率**。OpenAI 请求使用稳定的会话缓存键，Anthropic 和 OpenRouter 上的 Claude 在连续工具调用中能复用更多已发送的上下文。调整了长工具结果的保留规则，减少历史内容变化导致的缓存失效。
- **改进 GitHub Release 发布**。修复审核时填写的发布说明未随版本保存的问题。上传中断后可从 GitHub 草稿继续，并校验附件后再发布。此功能使用系统 PATH 中的 GitHub CLI（`gh`）。
- **修复 RSI 验证和回滚**。完善停止条件与无效候选的回滚处理，正确识别带终端颜色的测试输出，并修复历史重放和异常指标处理。
- **修复后台任务隔离**。后台任务的待办只显示在所属会话，返回结果时会尊重上级会话的目标暂停状态。
- 补充 RSI 和 Memory 2.0 的技术文档。

## 下载与运行

- [macOS Apple 芯片 DMG](https://github.com/songguomix/ConeCode/releases/download/v2.4.26/ConeCode-2.4.26-arm64.dmg)
- [Windows x64 安装程序](https://github.com/songguomix/ConeCode/releases/download/v2.4.26/ConeCode.Setup.2.4.26.exe)
- [Linux x64 AppImage](https://github.com/songguomix/ConeCode/releases/download/v2.4.26/ConeCode-2.4.26.AppImage)

Linux 用户在下载目录打开终端，为 AppImage 添加执行权限后启动。

```bash
chmod +x ConeCode-2.4.26.AppImage
./ConeCode-2.4.26.AppImage
```

可用 SHA-256 校验清单核对下载文件。 [下载 SHA256SUMS-2.4.26.txt](https://github.com/songguomix/ConeCode/releases/download/v2.4.26/SHA256SUMS-2.4.26.txt)
