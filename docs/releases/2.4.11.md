# ConeCode 2.4.11

- 重构左侧栏：工作区按项目分组并优先展示，项目内直接新建会话、关闭项目或打开文件夹；新增滑入式侧栏外壳，窄窗口下可用键盘呼出，焦点、遮罩与退出动画完整可访问。该方向来自社区贡献者 IwakuraRin 的 PR #2，合并时一并修复了文件浏览器、已关闭项目会话与多根目录恢复等回归。
- 桌面操控改为按应用生效：默认只观察和操作目标任务所在的单个窗口，观察结果包含窗口范围与元素目标，新增 `desktop.press`（目标 id 或截图坐标）与 `desktop.set_value`；整屏模式保留为显式选项。
- 移除工具轮次上限：一次运行不再在 200 个工具轮次后无提示中断，只有模型完成、等待用户操作、出错或用户手动停止才会结束。
- GitHub 插件新增回复助手页签，可在应用内查看并回复 Issues / PR 评论；Memory Dream 支持项目隔离的分层记忆整理、Wiki 与历史保留。
- 需求梳理先读取有界项目快照并识别技术栈，再向用户提问；编辑历史消息改为先预检、再回滚已应用的改动、最后截断，避免对话与磁盘代码不一致。
- 修复测试沙箱进程回收导致的偶发失败。

## 安装包

| 平台 | 架构 | 格式 | 签名 |
| --- | --- | --- | --- |
| macOS | Apple Silicon / arm64 | DMG | 本机 ConeCode 自签证书签名 |
| Windows | x64 | NSIS EXE | 未签名，沿用上一版本配置 |
| Linux | x64 | AppImage | 未签名 |

本机 macOS 签名不包含 Apple 开发者签名或公证。三端构建命令为 `npm run dist:all`，明确指定各平台架构。
