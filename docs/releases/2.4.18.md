# ConeCode 2.4.18

- 新增对话归档。Chat、Work 和 RSI 对话可归档、查看和恢复，保留消息与项目绑定，归档后已启动的任务继续运行。
- 修复 ConeCode Free 状态和模型目录的重复请求，免费服务请求支持系统代理与 PAC 配置。优化 HTTP 429 的提示和等待逻辑，遵循服务端返回的重试时间。
- 完善电脑操控悬浮预览，显示操作指针与点击反馈，支持在预览中手动点击、输入和刷新画面。
- 新增自动截图插件，可调用工具抓取 ConeCode 窗口、嵌入预览页或屏幕，供模型检查界面。
- 增加 GPT 系列模型工程约束的会话级选择，并修复桌面渲染器加载相关模块时的启动错误。
- 优化本地存储读取、文件搜索、提示词与 Token 用量处理。
