# ConeCode 2.4.16

- RSI 费用锁开启时才向模型提供费用查询工具和预算指引。关闭后，发送给模型的历史中会隐藏此前的费用查询结果。
- 记忆设置新增「自动整理错误记忆」，默认关闭。启用后，模型会根据用户的明确纠正，每轮最多移除一条符合条件的推断记忆。已确认或受保护的记忆不会被自动移除。
