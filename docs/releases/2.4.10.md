# ConeCode 2.4.10

- 新增操作悬浮预览：独立原生窗口置顶显示，整块画面可拖动，没有按钮、标题栏或外框。在主界面「电脑操控」中打开和关闭，停止操控后清空画面。
- 新增 DSH 兼容插件市场，支持固定版本与 Git 提交安装、配置、日志、启用与禁用、更新回滚和卸载，分别展示作者声明与实际兼容结果。
- 升级 Memory 2.0，加入项目隔离、分层记忆、版本历史、检索、旧数据迁移，以及可配置的 REST / Google Drive 同步。
- 改进 RSI 会话布局、历史恢复、执行证据和预算检查，加强候选改动范围与实测收益校验。
- 改进可调整面板布局、消息输入、空会话复用、流式重试、模型选择和多语言界面。
- 源码新增独立 Computer Use Agent runtime，包含 Chromium/macOS 驱动、恢复日志、CLI、SDK、MCP 和控制台。该运行时单独安装运行，未内置桌面安装包。

## 安装包

| 平台 | 架构 | 格式 | 签名 |
| --- | --- | --- | --- |
| macOS | Apple Silicon / arm64 | DMG | 本机 ConeCode 自签证书签名 |
| Windows | x64 | NSIS EXE | 未签名，沿用上一版本配置 |
| Linux | x64 | AppImage | 未签名 |

本机 macOS 签名不包含 Apple 开发者签名或公证。三端构建命令为 `npm run dist:all`，明确指定各平台架构。
