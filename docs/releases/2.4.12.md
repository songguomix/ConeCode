# ConeCode 2.4.12

- 后台任务卡片增加间距和列表留白；运行中的对话支持排队消息，代码改动可直接预览差异。
- 桌面操控聚焦于选定的应用窗口，改进 macOS 和 Windows 的截图预览与窗口状态处理。
- 改进远程对话中的提问与回答关联，以及远程 RSI 控制和连接状态。
- 优化 Memory Dream 的项目记忆整理、Wiki 更新和完成状态；设置中可检查更新并下载安装包。
- 源码新增可离线运行的 Aegis AISearch 后端模块，用于批量审查搜索候选链接，无需单独安装 Aegis。
