# ConeCode 2.4.20

本版补齐了 2.4.19 发行包遗漏的桌面端改动，并保留该版本的长期记忆优化。

- 新增子智能体面板，可从侧边栏查看委派任务、执行过程和结果。
- 更新电脑操控面板、目标窗口选择和悬浮预览；macOS 增加屏幕录制权限恢复入口。
- 新增 Aegis 搜索结果审查界面，支持本地审查，也可配置 VirusTotal 查询域名信誉。
- 改进目标进度显示和 RSI 验证，按实际执行的命令、目录和文件变更记录验证结果。
- 更新内置提示词。核心、Chat、Plan、Review、Goal、编排和 RSI 模板要求先说明「意图理解」，列出核心目标、关键约束和执行路径。
- Goal 提示词要求完成子任务后继续推进并在结束前核验；RSI 提示词明确冻结指标、验证命令及最终截图验收。启用 GPT 工程约束时，下载时 SHA-256 校验和大文件读写的提示文案也已更新。
