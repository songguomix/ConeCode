# Catalog Format and Source Management

ConeCode reads two JSON catalog formats. It does not assume an official community
endpoint: the bundled catalog is a curated, pinned snapshot, and every additional
source is explicitly configured by the user.

## ConeCode catalog (`conecode-dsh-market`, formatVersion 1)

Generated by `scripts/sync-dsh-catalog.mjs` from the npm registry and GitHub API.
The generated file is [`resources/dsh-market/catalog.json`](../../resources/dsh-market/catalog.json).

```json
{
  "format": "conecode-dsh-market",
  "formatVersion": 1,
  "title": "…",
  "generatedAt": "2026-11-06T…",
  "baseline": { "version": "0.2.2-rc.1", "commit": "…", "…": "…" },
  "categories": [{ "id": "tools", "title": { "en": "Tools", "zh": "工具" } }],
  "plugins": [
    {
      "name": "dsh-plugin-health",
      "format": "dsh",
      "title": "…",
      "description": "…",
      "author": "…",
      "license": "MIT",
      "repository": { "url": "https://github.com/…" },
      "category": "tools",
      "labels": ["diagnostics"],
      "keywords": ["…"],
      "declared": {
        "engines": { "dsh": "…", "node": "…" },
        "peerDependencies": { "@deepseek-ai/dsh-tools": "…" },
        "dsh": { "bundle": { "patch": "./cordis.patch.yml" } }
      },
      "versions": [
        {
          "version": "3.0.5",
          "publishedAt": "2026-…",
          "source": { "type": "npm" },
          "engines": { "dsh": "…" },
          "peerDependencies": { "…": "…" },
          "dependencies": { "…": "…" },
          "integrity": "sha512-…",
          "tarball": "https://registry.npmjs.org/…"
        }
      ],
      "stats": {
        "npmDownloadsLastWeek": 6275,
        "githubStars": 4,
        "provenance": {
          "source": "npm registry + GitHub API",
          "retrievedAt": "2026-11-06T…",
          "note": "Counts are point-in-time observations and are never used as a compatibility signal."
        }
      }
    }
  ]
}
```

`stats` is optional. The UI hides a number when it is absent rather than
displaying zero or a fabricated value. `readme` and `screenshots` are optional
cache fields.

### Version sources

| `source.type` | Required fields | Install behavior |
|---|---|---|
| `npm` | `version` (exact SemVer) | `npm install <name>@<version>` |
| `git` | `url` (https), `commit` (lowercase 40 hex), optional `subdir` | `npm install git+<url>.git#<commit>` or `...#<commit>&path:/<subdir>` |
| `local` | `path` | copied/npm-installed from the absolute path |
| `bundled-example` | `path` | first-party sample copied into the profile |

The installer re-reads the installed `package.json` and refuses a resolved
name/version that differs from the catalog claim.

## DSH official format 1

A configured remote or local source can also be a DSH market index with
`"format": 1`. ConeCode validates the subset it can display:

- `title`/`description` localized text;
- `metadata.categories`, `labels`, `keywords`, `sortKeys`;
- plugin `name`, `title`, `description`, `author`, `homepage`, `repository`;
- versions with `version`, `publishTimestamp`, `source` (`npm` or `git`),
  `engines.dsh`.

It converts those into the internal model; missing fields (for example a license
or dependency list) stay missing. It does not claim to implement the official
market detail-document/image protocol.

## Source management

Sources are stored in `market-state.json` and can be:

- **bundled** — the local pinned catalog and the native sample; cannot be removed;
- **remote** — an `https://` URL (or localhost HTTP) that returns either format;
- **local** — a directory containing `catalog.json` or a direct JSON file.

For each source the Sources page shows:

- title, location, entry count;
- last successful sync time;
- last error;
- whether the displayed entries are a stale cache.

A failed remote/local refresh never erases the last usable cache. If no cache
exists, the source contributes no entries and the error is visible. A remote
response is size-limited and must be valid JSON; redirects are followed by the
fetch client, but the URL is validated and cannot carry credentials.

## Regenerating the bundled catalog

```sh
node scripts/sync-dsh-catalog.mjs
```

The script:

- pins the plugin list in `scripts/sync-dsh-catalog.mjs`;
- downloads npm packuments and keeps up to 30 newest exact versions per plugin;
- records `dist.integrity`, tarball URL, engines, peers, dependencies, license,
  deprecation and unpacked size;
- fetches last-week npm downloads and GitHub stars (if available), stamping
  `retrievedAt`;
- captures the latest README and real screenshots (badges are filtered out);
- writes `resources/dsh-market/catalog.json`.

It never uses a star count as a compatibility signal and never invents a rating.
Changes to the plugin list are deliberate curation decisions; add the matching
verification record separately in `resources/dsh-market/verifications.json`.
